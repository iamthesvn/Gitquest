Three Modes

Learn

11 guided lessons with animated ASCII art. Watch how init, config, add, commit, push, branch, switch, merge, status, log, and pull actually work. No typing required.

Game

20 chapters across 4 volumes set at Halcyon, a fictional tech company. Real office scenarios, real characters, real stakes. Wrong answers cost XP. Hints are available but penalised.

Gitlings

5 rustlings-style exercises where you type real git commands into isolated temporary repositories. Commands are executed and verified. No story, no XP — just reps.

Real Git Execution

Gitlings spins up isolated temp repos, runs your commands via std::process::Command, and inspects the actual repository state. Not string matching. Real git.

Synthesised Audio

3 ambient music tracks + sound effects generated at runtime via rodio. No audio files to bundle. Mute with M.

Persistent Progress

Your story progress and Gitlings completion status are saved to ~/.gitquest/save.json. Resume where you left off.
