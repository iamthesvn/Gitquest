What is GitQuest?

GitQuest is a terminal-based educational game built in Rust that teaches Git through three complementary modes:

  • Learn — 11 guided lessons with animated ASCII art demonstrations. No typing required.
  • Game — A 20-chapter narrative across 4 volumes set at Halcyon, a fictional tech company.
  • Gitlings — 5 hands-on exercises where you type real git commands in isolated temporary repositories.

Quick Start

cargo install gitquest
gitquest

Why GitQuest?

Most Git tutorials are either dry reference docs or contrived examples with no stakes. GitQuest puts you in real office scenarios — production is down, your CEO is in Slack, and you need the right command now. You remember stories, not bullet points.

Use Cases

  • Solo learners — Pick a mode based on your energy: Learn when tired, Game when motivated, Gitlings when you want reps.
  • Workshops & classrooms — Learn mode works for live demos. Gitlings works for paired exercises.
  • Onboarding — New hires can work through the Halcyon saga to learn team git workflows in context.
  • Interview prep — Gitlings exercises cover the exact commands that come up in technical interviews.

Tech Stack

Built with Rust 2024, ratatui 0.30, and rodio 0.19. Audio is synthesised at runtime — no bundled files. Runs on macOS, Linux, and Windows.
